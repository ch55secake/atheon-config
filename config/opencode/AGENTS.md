# Agent Guidelines

These are the default working preferences for this configuration.

## Commits

- Use [Conventional Commits](https://www.conventionalcommits.org/) for every commit.
- Keep commit messages concise and clear, with an appropriate type and scope when useful.

## Pull Requests

- Create a pull request when a change has been completed. 
- When creating one, follow the repository's pull request template completely. Do not bypass, replace, or invent a different format.
- Never include the validation that you did when you raised the pull request. 

## Changes and Testing

- Prefer small, focused changes that match the existing project conventions.
- Test changes thoroughly using the most relevant available checks before reporting them as complete.
- If tests cannot be run, say so clearly and explain what was checked instead.

## Communication

- Keep responses concise, clear, and somewhat informal.
- State what changed, how it was verified, and any remaining limitations without unnecessary detail.
